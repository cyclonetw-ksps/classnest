# 計畫：classnest 班級經營常駐網站

## 目標

一位或幾位同校老師共用一套網站，經營一個以「組」為單位上課的班級（第一個使用者是 Cyclone 的資源班）。完成後可觀察到：

- 老師用 Google 帳號登入，可邀請同校其他老師加入，權限相同，每筆加分紀錄記下是哪位老師給的。
- 老師維護學生名單與組別；一位學生可同時屬於多個組（例如國語某組與數學另一組）。
- 老師按自訂理由一鍵加分，按錯可撤銷；分數只增不減，達到老師自訂門檻就解鎖對應獎勵，發完後標記已發放。
- 學生在個人或共用平板上點自己的頭像，再依序點三張圖卡登入；只有老師開放簽到的那幾分鐘能簽到，大螢幕即時列出已簽到的人，老師可撤銷。
- 每位學生養一隻寵物（從幾種中選一種並取名，可以點牠看反應）：成長階段看累積分，心情看最近 7 天得分；很久沒得分只會「想你了」，不會生病。寵物圖由 AI 生成。
- 大螢幕顯示本節組別學生的寵物，不顯示分數排行；精確分數只出現在學生自己的頁面與老師端。
- 學期初設定節次時間與週課表（每節哪組上什麼科），每週在各節填教學內容與作業，可複製上週、可臨時換課或停課。
- 大螢幕依課表自動倒數下課或上課時間，上課前提醒這節是哪組、要帶什麼，並有老師自訂分鐘數的視覺計時器。
- 學生在自己頁面勾「寫完了」，老師確認後自動加上該作業設定的分數，可整組一鍵確認。
- 聯絡簿以組發送，可對個別學生加註；學生在自己頁面看到，老師可一鍵產生某組或某生的聯絡簿文字，複製貼到 LINE。
- 老師可在後台產生 agent 金鑰，agent 透過 MCP 讀寫公布欄，之後各切片再依需要開放課表與聯絡簿；每把金鑰的權限只限該切片開放的內容，老師也能全部手動操作。
- 老師有一個公布欄：自訂面板（一欄便條卡），貼文字、連結、回家作業（可放大 QR Code）；面板可標組別、可設私人或分享。代課老師、學生、家長用一個分享連結（可加 4 位數通關碼、可換新連結）看分享的面板，並可依組切換，看不到任何學生資料。
- 網站顯示的標題由老師在後台修改。其他老師照安裝說明，用自己的 GitHub 與 Cloudflare 帳號部署一套，程式不含任何人的私有設定。

## 非目標

- 不做跨校平台：一套網站只服務一個班，別校自己架。
- 不做家長帳號，也不在第一版接 LINE 官方帳號推播。
- 不做扣分、寵物生病或死亡、點數兌換商店、寵物裝飾收集。
- 不做音量偵測、工作符號或紅綠燈。
- 不匯入學校課表檔案。
- 不存生日、身分證字號、障礙類別、家長電話等個資。
- 不複製其他專案的程式碼。ClassIsland、Classworks、puti-classroomscreen、hsps-point-bank、Class-Manager 只參考概念。
- 不用人臉辨識或其他生物特徵。

## 現況盤點

已查證：

- Cyclone 的 cyclone-board 已在 Cloudflare Workers 上運作：每份資料一個 Durable Object（內建 SQLite）、Preact 前端、權限檢查都在伺服器端、agent 用金鑰走 MCP（Streamable HTTP）、測試跑在 Cloudflare 的 Workers 測試環境、合併後由 GitHub Actions 部署。新專案沿用同一套架構與做法，但程式重寫，不共用 repo。
- cyclone-board 的老師登入是 Cloudflare Access。本案改用 Google 登入，因為要讓其他老師自架；代價是每位自架老師都要自己建一組 Google 登入設定，安裝說明要寫清楚。
- 本機 gh 目前只登入 cyclone-tw。新 repo 要放在 Cyclone 以學校信箱註冊的另一個 GitHub 帳號；Cloudflare 也用同一個學校帳號開通。該 GitHub 帳號是 cyclonetw-ksps，本機 gh 已登入（預設帳號維持 cyclone-tw，本專案的指令另外指定 cyclonetw-ksps）。
- 受管 review 在設定檔中沒有寫死 repo 擁有者，但 Mac mini review runner 是否讀得到另一個帳號的 repo 尚未驗證。
- Modern Web Guidance 已安裝，前端互動照它的指南寫。
- GitHub 上找不到同時具備分組、自訂門檻獎勵、圖卡簽到、MCP 的開源專案。

## 模組切分

依使用者功能切垂直切片，每一刀都能單獨示範：

1. 名單分組與快速加分：老師 Google 登入與邀請、學生與組別（一人多組）、加分理由、一鍵加分與撤銷、累積分、獎勵門檻與已發放、網站標題設定。所有後續切片依賴這一刀。
2. 公布欄、分享頁與 agent 入口（#9，取代原「Agent 入口」）：自訂面板與文字、連結、作業便條（含 QR Code），面板可標組別與分享；全班一個分享連結加可選通關碼與換新連結，分享頁可依組切換；後台產生與停用 agent 金鑰，MCP 只能讀組別名稱與讀寫面板、便條。名單與加分不開放給 agent，之後各切片若要開放再各自補 MCP 工具與權限。依賴 1。
3. 學生登入與簽到（#25，2026-11-27 Cyclone 決定 3-1～3-8 全照建議）：分兩個 PR。3a：老師把某台平板設成共用或個人學生平板（同時登出那台的老師），只有學生平板能列出名單與登入；學生點組別、點頭像（名字第一個字加組別色）、依序點 9 張裡的 3 張圖卡；圖卡密碼由老師產生、可印；連錯 5 次停 5 分鐘；共用平板登入 10 分鐘、個人平板一直記住；學生頁顯示自己的分數、獎勵進度與所屬組最近一次已發送的聯絡簿與給自己的加註。3b：老師開放簽到（預設 10 分鐘）、學生簽到、大螢幕只列已簽到的顯示名、老師撤銷、紀錄保留 30 天。學生資料不開放給 agent。依賴 1。
4. 寵物：AI 生成各寵物各成長階段與心情的圖、選寵物、取名、摸摸看、成長與心情規則、大螢幕本節組別寵物、加分小動畫。依賴 3。
5. 課表與每週計畫（#14）：節次時間、週課表（週一到週五，每格組別、科目、預設要帶的東西）、每週內容與作業與要帶的東西、複製上週（只填空格）、臨時換課與停課（只影響那一週）；MCP 可讀課表與某一週、一次填整週內容，換課停課與改課表只給老師。依賴 1。
6. 大螢幕倒數與計時：6a 視覺計時器（#12，不依賴課表）；6b 依課表自動倒數下課與上課、上課前提醒組別科目與要帶的東西、上下課提示音（#16）。6b 依賴 5。
7. 聯絡簿（#22，2026-11-27 Cyclone 決定只做聯絡簿，作業沿用公布欄作業卡與課表）：一天一組一則（作業、要帶的東西、備註）、自動帶入當天課表、個別加註、存草稿與發送、分享頁顯示已發送的、一鍵複製到 LINE；MCP 可讀與草擬，發送只給老師。學生頁顯示留給切片 3。依賴 5。
8. 自架說明（#17）：`docs/self-hosting.md` 安裝文件、`.dev.vars.example` 設定範本、`pnpm test` 的私有值檢查、GitHub Actions 可手動部署；確認程式中沒有 Cyclone 的私有值。可與 5、6、7 平行。

## 驗收

- [ ] 未登入的人打開管理頁會被導向 Google 登入，伺服器拒絕未授權帳號的所有讀寫
- [ ] 第一位老師由部署設定指定；他可以用 email 邀請第二位老師，第二位老師登入後看到同一份名單
- [ ] 可新增、改名、停用學生
- [ ] 學生資料欄位只有顯示名、原班、導師稱呼、所屬組別
- [ ] 同一位學生可同時加入兩個以上的組，從任一組都看得到他
- [ ] 老師可新增自訂加分理由，每個理由各有自己的分數
- [ ] 按一下理由就替一位學生加分
- [ ] 按一下理由就替整組學生各加一次分
- [ ] 每筆加分紀錄都記下是哪位老師、在什麼時間加的
- [ ] 撤銷一筆加分後，累積分立即扣回這筆分數
- [ ] 撤銷造成分數低於門檻時，該獎勵立即改回未解鎖
- [ ] 老師可設定多個分數門檻，每個門檻各寫一項獎勵
- [ ] 學生累積分達到門檻時，該獎勵列為已解鎖
- [ ] 老師可把已解鎖的獎勵標記為已發放
- [ ] 後台改網站標題後，所有頁面的標題跟著改
- [ ] 在 iPad 寬度能完成加分流程，不需要左右捲動
- [ ] 在手機寬度能完成加分流程，不需要左右捲動
- [ ] 部署到 Cyclone 學校帳號的 Cloudflare 後，正式網址可以登入
- [ ] Cyclone 用真實名單試用一節課後回報可用
