# classnest

給「分組上課」的班級用的常駐網站：學生名單與分組、積分與獎勵、寵物養成、簽到、課表與倒數、作業與聯絡簿。老師可以手動操作，也可以讓 AI agent 透過 MCP 讀寫。

一套網站服務一個班，可以有幾位老師共用。程式跑在 Cloudflare Workers 免費方案上，其他老師可以用自己的 GitHub 與 Cloudflare 帳號部署一套。

開發中。規格與切片見 [docs/plans/2026-11-24-classnest.md](docs/plans/2026-11-24-classnest.md)，進度見 Master issue。
